# Placeholder result files

The JSON and NPZ files in `results/ridge/`, `results/snn/`, and
`results/controls/` were generated by
`scripts/_generate_placeholder_partner_results.py` so the figure
pipeline can be exercised end-to-end before every model has been
trained on real MC_RTT data.

Every JSON contains `"_placeholder": true` and every row's
`notes` field is marked. Real training runs simply overwrite
these files using the same canonical schema (see
`docs/data_interface.md`) and `scripts/generate_final_figures.py`
produces the publication figures unchanged.
